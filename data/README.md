# Data artifacts

- `raw/`: the downloaded UCI source, normalized-header CSV, and source/checksum metadata.
- `processed/`: train/validation/test arrays, fitted preprocessing, ordered feature names, and raw test features for hosted inference verification.

Both directories are generated by DVC stages, ignored by Git, and stored in the configured DagsHub DVC remote. Commit `dvc.yaml` and `dvc.lock`, not CSVs or arrays. Restore generated artifacts with `dvc pull`.
